# Infrastructure & Security Lab

## Overview

This repository exists to document my self-hosted infrastructure and cybersecurity lab.

The goal of this project is to build, operate, secure, and document a production-style home server while developing practical experience in Linux administration, Docker, networking, reverse proxies, DNS, monitoring, backups, and defensive security.

Rather than following isolated tutorials, this repository documents the complete engineering process—from planning and deployment to troubleshooting, documentation, and future expansion.

---

## Objectives

- Learn infrastructure engineering
- Improve Linux administration skills
- Build secure containerized services
- Practice networking and DNS
- Document architecture professionally
- Develop blue-team security skills
